# New note sequence diagram

```mermaid
sequenceDiagram
    actor user
    participant browser
    participant server
    
    user->>browser: submit new note form
    activate browser
    
    browser->>+server: POST https://studies.cs.helsinki.fi/exampleapp/new_note
    server-->>-browser: 302 Redirect /exampleapp/notes

    browser->>+server: GET /exampleapp/notes
    server-->>-browser: HTML document

    Note over browser,server: The browser parses the HTML and loads <link> and <script> tags
    
    browser->>+server: GET /exampleapp/main.css
    server-->>-browser: CSS file

    browser->>+server: GET /exampleapp/main.js
    server-->>-browser: JavaScript file

    Note over browser,server: The browser starts executing the JavaScript that loads the JSON
    
    browser->>+server: GET /exampleapp/data.json
    server-->>-browser: [{content: "note one "}, date: "2026-10-26T11:39:59.410Z"}, ...]

    deactivate browser    
    browser-->>user: rendered web page
